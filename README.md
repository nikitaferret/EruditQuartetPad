# EruditQuartetPad

Портативный пульт и экран зала для турниров по **«Эрудит-Квартету»** (ЛУК — «Логическая угадай-ка»): игра идёт за столами по 4 команды.

## Чистый старт

В репозитории нет личных данных: ни названий команд, ни счетов, ни фонов, ни
сохранённых турниров. Приложение стартует с пустого состояния, а всё, что вы
вводите, живёт только в вашем браузере (`localStorage`) и в памяти локального
сервера. В репозиторий эти данные не попадают.
## Возможности

- От **6 до 16** команд — по одной на строку, кнопка «Перемешать» для жеребьёвки.
- **«Сформировать таблицу»** — раскладка команд по столам и раундам.
- Ведение по раундам: текущий бой → **«Дальше / снять»** → **«Следующий стол»** →
  **«Завершить раунд»**, с откатом кнопкой **«Отменить»**.
- Пометка «Раунд сыгран» и переход к следующему столу — оператор всегда видит,
  что уже отыграно.
- **«Остановить игру»** — турнир завершён, чемпион выводится на зал.
- На зале — заставка «Эрудит-Квартет» до старта и сетка во время игры.

## Экран зала

Зал открывается отдельным окном браузера на другом мониторе в режиме приложения
(`--app`) со своим профилем. Кнопка «Экран зала» на пульте переключает монитор,
если их несколько.

## Быстрый старт

**Портативно (без установки Python).** Скопировать папку целиком, включая
`runtime\python\`, и дважды щёлкнуть `!ЗАПУСК.vbs`. Откроется пульт оператора;
окно консоли скрыто. Запасной запуск — `EruditQuartet.bat` (консоль видна; её
закрытие останавливает сервер).

**Из исходников.** Нужен Python 3.10+ (проверено на 3.12):

```bash
python serve.py
```

Порт по умолчанию — **3852**, переопределяется переменной окружения `PORT`.

Браузер: Edge или Chrome (для зала используется режим приложения `--app`).
Система: Windows 10/11 64-bit.

## Портативный runtime

Приложение работает на **embeddable CPython 3.12**, который лежит в `runtime\python\`.
Раньше папка копировалась вместе с проектом — в репозитории её нет: это 22 МБ
бинарников, которые бессмысленно держать в git.

Восстановить runtime одной командой из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\get-runtime.ps1
```

Скрипт скачивает официальный `python-3.12.10-embed-amd64.zip` с python.org и
распаковывает его в `runtime\python`. Ничего не ставится в систему, права
администратора не нужны. Если `runtime\python\python.exe` уже есть — скрипт
ничего не делает.

Никаких внешних зависимостей: `serve.py` использует только стандартную
библиотеку Python.

## Структура

```
EruditQuartetPad/
  !ЗАПУСК.vbs              запуск без окна консоли
  EruditQuartet.bat        запуск (портативно)
  serve.py                 локальный HTTP-сервер, только stdlib
  index.html               пульт оператора
  display.html             экран зала
  css/app.css              оформление
  js/engine.js             раскладка по столам и раундам
  js/operator.js           логика пульта
  js/render.js             отрисовка
  js/display.js            отрисовка зала
  js/bus.js                шина между окнами
  logo.svg, app.ico
  scripts/get-runtime.ps1   восстановление runtime\python
```


## HTTP API

Локальный сервер слушает `127.0.0.1:3852` и отдаёт состояние залу через
обычные JSON-эндпоинты (интеграции и автоматизация):

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/state` | текущее состояние турнира |
| `POST` | `/api/state` | записать состояние турнира |
| `GET` | `/api/status` | статус сервера, мониторы, браузер |
| `GET` | `/api/open-display` | открыть экран зала |
| `GET` | `/api/cycle-display` | переключить монитор зала |
| `GET` | `/api/reload-display` | перезагрузить окно зала |
